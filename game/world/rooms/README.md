# Generated rooms

Every `.tscn` here (tutorial/, f1/, boss_f1.tscn) and `world/tiles_floor1.tres` is generated by `tools/build_rooms.gd` from the ASCII layouts in that file. Changes made in the Godot editor are overwritten the next time it runs.

To change a room, edit its layout in `tools/build_rooms.gd` and rerun:

    godot --headless --path game -s res://tools/build_rooms.gd

The script checks every layout before writing anything: all floor reachable from the entry, exit reachable, no spawn within 96 px of the entry, one chest spot per random template.
