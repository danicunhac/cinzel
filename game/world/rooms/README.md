# Generated rooms

Every `.tscn` here (tutorial/, f1/, boss_f1/2/3.tscn) and `world/tiles_floor1/2/3.tres` are generated by `tools/build_rooms.gd` from the ASCII layouts in that file (30 x 16 tiles of 16 px, 480 x 256). Changes made in the Godot editor are overwritten the next time it runs.

To change a room, edit its layout in `tools/build_rooms.gd` and rerun:

    godot --headless --path game -s res://tools/build_rooms.gd

The script checks every layout before writing anything: all floor reachable from the entry, exit reachable, no spawn within 144 px of the entry, one chest spot per random template, and (non-boss rooms) a 2x2 floor block near the entry for the `StairsSpot` marker, where a floor's first room shows its stairs down. The entry door is a `Back` RoomDoor: shut in a floor's first room, otherwise it leads back to the previous room.

## Painted rooms

A room whose painting exists at `assets/rooms/<room id>.png` (480 x 270) shows it as the `Background` sprite. The `Walls` tile layer stays for collision only (hidden), the doors get overlay sprites from `assets/rooms/doors.png` (the exit's `Sprite` swaps locked/open in `room_door.gd`), the torch cells get `PointLight2D`s and an `Ambient` CanvasModulate darkens the room a little. The painting draws the thin top wall's brick face over floor row 1, so `WallFaceBlockers` (a StaticBody2D) blocks that row (not under a top-wall door) plus a 4 px strip inside each side wall; no spawn or chest may sit in row 1 under a thin top wall (the build checks it). A room without a painting keeps the tile look, so a new template (floor 2 or 3) works at once and can be painted later:

1. Add the layout to `ROOMS` (with `"floor": 2` or `3`) and run `build_rooms.gd`; it also writes `art-src/gen/rooms/layouts.json`.
2. `python3 -I art-src/build_rooms_art.py . blockout`, upload `art-src/gen/rooms/blockout/<id>@4x.png`, edit it with the tower key art as second image (prompts in `docs/assets.md`).
3. Check candidates with `build_rooms_art.py . overlay <id> <png> <out>`, copy the chosen one to `art-src/gen/rooms/<id>.png`, run `build_rooms_art.py . final <id>`.
4. Run `build_rooms.gd` again so the scene picks up the painting.

If a layout changes, its painting must be redone: the collision follows the layout, not the picture.
